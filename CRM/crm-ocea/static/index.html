1. Objectif du CRM

Le CRM H2EAUX SERVICES est l'outil de comptabilisation interne d'OCEA pour les campagnes de relevés de compteurs via Harmonie HOC. Il permet de :

  • Centraliser le patrimoine compteur (PAT) et les relevés effectués (CST)
  • Classer automatiquement chaque compteur (GPA, logement, radio, compteur général)
  • Calculer le chiffre d'affaires HT, la TVA 20 % et le total TTC
  • Suivre les trajets (TRN), le carburant et la marge nette
  • Gérer les fiches par code ensemble (accès, contacts, commentaires)
Le CRM tourne en local sur votre PC (demarrer.bat → http://127.0.0.1:8080). Les données sont stockées dans SQLite, sans cloud.

2. Logique métier & règles de facturation

✓

Relevé facturable

Un compteur est facturable uniquement si l'index a été saisi sur le terrain : nature IndexReel avec une valeur d'index présente dans le fichier CST.

✗

Non relevé

Si la nature est Pas d'index ou qu'aucune valeur n'est saisie → le compteur est non facturé (passage sans relevé, accès impossible, etc.).

Matching PAT ↔ CST

Les fichiers CST contiennent l'index relevé, la date et les observations — mais pas le type de compteur (visuel, radio, GPA…). Cette information vient du fichier PAT, via l'identifiant commun IDPdc.

C'est pourquoi le PAT doit être importé avant les CST : sans PAT en base, le CRM ne peut pas classifier correctement les compteurs.

Règle GPA estimé

Si un relevé a un index OK mais qu'aucun PAT correspondant n'est trouvé en base, le CRM applique la règle métier OCEA : facturation en Visuel extérieur GPA à 0,70 € HT (environ 90 % des cas terrain sans PAT). Une alerte orange vous signale ces relevés.

4. Fichiers Harmonie HOC — rôle de chaque dossier

PAT

Patrimoine — HOC/DBXML/PAT/PAT_*.xml

Liste de tous les compteurs à relever : type, emplacement, adresse, code ensemble, IDPdc. Import en début de campagne.

CST

Constats / Relevés — HOC/DBXML/CST/*CST_*.csv

Résultats terrain : index, date, consommation, observations. Import en fin de relevé ou fin de semaine.

TRN

Tournées — HOC/DBXML/TRN/TRN_*.xml

Planning, GPS, contacts client, récap par fluide. Importé avec « Tout importer » ou automatiquement — sert au calcul km/carburant.

6. Étape 1 — Importer le PAT (début de campagne ou de tournée)

  1. Synchronisez votre PDA / Harmonie pour récupérer les fichiers PAT dans le dossier HOC/DBXML/PAT/.
  2. Lancez le CRM via demarrer.bat.
  3. Dans la barre latérale gauche, cliquez sur ↑ Importer PAT.
  4. Le CRM lit tous les fichiers PAT_*.xml et enregistre chaque compteur (IDPdc) en base SQLite.
  5. Les codes ensemble (ex. BC455) sont créés automatiquement pour les fiches immobilières.

Quand réimporter le PAT ?

  • Au lancement d'une nouvelle campagne de relevés
  • Au début de chaque semaine de tournée, avant que Harmonie ne purge les PAT
  • Quand de nouveaux ensembles apparaissent dans Harmonie
Bouton vert « Importer PAT » = action prioritaire. Ne pas importer les CST sans PAT préalable si vous voulez une classification fiable.

7. Étape 2 — Relevés terrain avec Harmonie

Sur le terrain, avec Harmonie HOC v9.4 :

  • Ouvrez la tournée assignée (fichier TRN)
  • Pour chaque compteur : saisissez l'index réel lu sur le compteur
  • Si le compteur n'a pas pu être relevé → laissez Pas d'index (non facturable)
  • Ajoutez une observation si nécessaire (accès, anomalie…)

Pendant cette phase, vous pouvez compléter les fiches ensemble dans le CRM (codes d'accès, contacts) si vous avez déjà importé le PAT — pratique pour préparer les prochains passages.

8. Étape 3 — Importer les CST (fin de relevé, fin de semaine…)

  1. En fin de journée, de tournée ou de semaine : synchronisez Harmonie vers le PC.
  2. Vérifiez que les fichiers CST sont dans HOC/DBXML/CST/ (fichiers *CST_*.csv).
  3. Cliquez sur ↑ Importer CST dans la barre latérale.
  4. Le CRM associe chaque ligne CST au PAT via IDPdc, calcule le statut (OK / non relevé), la catégorie et le montant.
  5. Les relevés déjà importés ne sont pas dupliqués (import incrémental).

Fréquence recommandée :

  • Fin de journée — suivi quotidien du CA et des non-relevés
  • Fin de semaine — bilan hebdomadaire pour facturation
  • Fin de campagne — export CSV final et rapport partagé
Si l'alerte orange « relevés sans PAT » apparaît : réimportez le PAT puis recliquez sur Importer CST, ou utilisez « Tout importer ».

9. Étape 4 — Analyser & facturer dans le CRM

  1. Ouvrez le Tableau de bord : vérifiez le CA TTC, la répartition par type.
  2. Utilisez les filtres (catégorie, date, code ensemble) pour isoler une tournée ou un site.
  3. Consultez l'onglet Relevés pour le détail ligne par ligne.
  4. Complétez les Ensembles (accès, contacts, commentaires).
  5. Vérifiez les Kilomètres et la marge après carburant.
  6. Export CSV pour la compta ou Partager un rapport par mail.

  • Bandeau KPI hero — CA TTC en évidence, relevés OK, total HT filtré, non relevés
  • Barre totaux — Total global HT/TVA/TTC + total de la catégorie si un filtre est actif
  • Grille tarifaire — Rappel des 4 tarifs unitaires HT
  • Cartes indicateurs — CA HT, TVA, TTC, km, carburant, marge nette
  • Cartes par catégorie — Nombre de relevés et montant HT par type (GPA, logement, radio, CG)
  • Graphiques — Barres OK vs non relevés, camembert répartition CA HT

11. Rubrique : Relevés

Tableau détaillé de tous les compteurs relevés, filtré selon vos critères actifs :

  • Date — Date et heure du relevé
  • Statut — Vert = facturable (index OK) · Rouge = non relevé
  • Type — Catégorie de comptage (GPA, logement, radio, CG)
  • Code / Ensemble / Ville — Localisation immobilière
  • Index — Valeur saisie sur le terrain
  • Montant € — Montant HT facturé (0 € si non relevé)
  • Observation — Commentaire Harmonie

12. Rubrique : Ensembles

Gestion au niveau du code ensemble (ex. BC455) — pas compteur par compteur :

  • Liste — Tous les ensembles importés (PAT/TRN) avec nb relevés OK et CA HT
  • Fiche ensemble — Cliquez une ligne pour éditer :
    • Code d'accès — Digicode, clé, badge, local technique
    • Contacts — Syndic, gardien, téléphone, email (pré-rempli depuis TRN si disponible)
    • Commentaires — Notes campagne, particularités du site
Les contacts TRN ne remplacent pas vos saisies manuelles : le CRM préserve vos modifications.

13. Rubrique : Kilomètres

  • Calcule la distance entre sites à partir des coordonnées GPS des fichiers TRN
  • Estime le coût carburant (prix litre + consommation configurables via ⚙ Carburant)
  • Affiche la marge nette = CA HT − coût carburant
  • Tableau des segments : heure de départ, site de départ → site d'arrivée, distance km

Les distances sont calculées « à vol d'oiseau » entre points GPS — ordre des sites = heure de planning TRN.

15. Export, partage & mail

  • ↓ Export CSV — Télécharge tous les relevés filtrés (Excel, compta)
  • ⎘ Partager — Génère un lien de rapport consultable (actif tant que le CRM tourne)
  • ✉ Mail — Ouvre votre client mail avec un résumé CA, km, marge + lien rapport
  • ⚙ Carburant — Modifier prix essence (€/L) et consommation (L/100 km)

Boutons latéraux d'import :

  • Importer PAT — Patrimoine uniquement (début campagne)
  • Importer CST — Relevés uniquement (fin relevé)
  • Tout importer — PAT + TRN + CST en une fois

16. Alertes & cas particuliers

Alerte orange — Sans PAT

Des relevés OK existent sans PAT correspondant. Réimportez le PAT puis les CST.

Note GPA estimé

Relevés classés GPA à 0,70 € faute de PAT — montant correct mais classification approximative.

Import incrémental

Relancer un import CST n'ajoute que les nouveaux relevés, sans doublons.

Recalcul automatique

Chaque import CST recalcule statuts, catégories, montants et flag pat_trouve.

17. Bonnes pratiques & FAQ

Dans quel ordre importer ?
Toujours PAT d'abord, puis CST. TRN est optionnel mais recommandé pour km/contacts.
Harmonie a supprimé mes PAT, que faire ?
Importez le PAT chaque semaine tant que les fichiers existent. Sans PAT, le CRM facture en GPA estimé.
Comment voir le CA d'une seule journée ?
Filtre Date campagne → le bandeau KPI et les totaux se mettent à jour.
Comment voir uniquement les relevés radio ?
Filtre Catégorie → Radio à distance. Le total radio s'affiche en plus du global.
Où sont stockées mes fiches ensemble ?
En base SQLite locale (crm-ocea/data/ocea_crm.db), conservées entre les imports.
Le CRM fonctionne-t-il hors ligne ?
Oui, 100 % local. Aucune connexion internet requise sauf pour les polices Google et Chart.js.
